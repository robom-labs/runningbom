# 코스 시험용 고정 자료

`data/course-base.json`과 `data/course-elevation.json`은 자동 작업이 매일 바꾸는 실제 자료다.
대회가 끝나면 높이 정보가 비거나 코스가 줄어서, 그 자료에 기대던 시험이 깨졌다(2026-11-28).

이 폴더는 높이 정보 2개(MBN 하프·10K)가 있던 2026-11-28 자료(커밋 68f5d1d)를 그대로 떠 둔 것이다.
검증 규칙을 시험하는 코드는 이 고정 자료를 읽는다. 실제 자료가 맞는지는 `course-catalog-pipeline` 시험이 따로 본다.
