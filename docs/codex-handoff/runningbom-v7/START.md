# 러닝봄 V7 UX 전면개편 시작문구

Claude Code 또는 Codex 채팅창에 아래 문장을 그대로 붙여 넣는다.

```text
러닝봄의 현재 기능을 삭제하지 않고, 사용자가 느끼는 복잡성만 제거하는 V7 UX 전면개편을 수행해라.

작업 전에 저장소 안의 다음 파일을 처음부터 끝까지 전문으로 읽어라.

docs/codex-handoff/runningbom-v7/01_SIMPLE_SPORTY_UX_MASTER.txt

이 파일을 러닝봄 V7 정보구조·UI·디자인·폴더구조 작업의 실행 정본으로 적용해라. 궁극의 로봄 v1.4가 있으면 그것을 최우선으로 지켜라.

최신 origin/main과 실제 설치·배포 상태를 먼저 확인하고, 열린 PR #71을 포함해 navigation·V6 coaching·UI 관련 현재 작업을 전수 확인해라. 오래된 #35·#36·#39·#55 같은 PR을 최신 결과라고 가정하지 마라. 현재 main에 들어간 기능과 아직 PR에만 있는 기능을 분리하고, 중복 구현·회귀·충돌을 막아라.

핵심 방향은 기능 삭제가 아니라 기능 은닉·재배치·맥락화다.

- 하단 탭과 좌상단 drawer가 동시에 존재하는 이중 내비게이션을 없애라.
- 최상위 목적지는 정확히 `오늘 / 훈련 / 달리기 / 찾기 / 나` 다섯 개로 정리해라.
- 기존 모든 기능을 Feature Preservation Matrix로 새 위치에 100% 매핑해라.
- 홈은 오늘 행동 하나와 이번 주·목표 대회·최근 기록만 우선 보여라.
- 훈련은 `오늘 / 내 계획 / 라이브러리`로 나눠라.
- 달리기는 단순한 Run Dock과 별도의 Active Run 전체화면으로 나눠라.
- 대회·러닝화·러닝 지식은 `찾기`에 모아라.
- 기록·분석·배지·보관함·프로필·설정은 `나`에 모아라.
- 설정 첫 화면은 6개 요약 row만 보여 주고, 세부 설정은 하위 화면과 고급 영역으로 옮겨라.
- 연결되지 않은 로그인·연동·커뮤니티와 개발자 SHA·schema를 일반 첫 화면에 노출하지 마라.
- 기존 warm lifestyle 느낌을 줄이고, 파일의 Sport Signal System과 Run Rail·Run Dock을 바탕으로 깔끔하고 성인다운 sport-tech 디자인을 구현해라.
- 기존 V6 음성코치, 계획, 일회성 훈련, 도전, 보조 프로젝트, 대회, 러닝화, 기록, 배지, 메트로놈, GPS Preview, 저장 데이터와 ID는 보존해라.

문서나 목업만 만들고 멈추지 마라. 실제 코드·화면·라우팅·저장 호환·테스트·화면 캡처·시각 비교·접근성·성능까지 구현하고, 원자 커밋과 Draft PR로 남겨라.

새 Android 권한·새 네이티브 의존성·Play Console 변경이 필요하면 현재 심사 중 Production에 섞지 말고 POST_REVIEW로 분리해라. 실기기·사람 시각검토가 필요한 항목은 DEVICE_REQUIRED 또는 VISUAL_REVIEW_REQUIRED로 정직하게 남겨라.

파일의 첫 응답 형식을 지킨 뒤 Wave 0부터 즉시 시작해라.
```
