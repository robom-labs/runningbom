# 러닝봄 스트릭·배지 규칙

## 현재 규칙 버전

`BADGE_RULE_VERSION`은 `2026.07-v1`이다.

## 하루와 주간 경계

- 기본 timezone은 `Asia/Seoul`이다.
- 하루는 현지 시각 04:00에 바뀐다.
- 같은 하루에 여러 활동이 있어도 움직임 일수는 한 칸이다.
- 주간은 월요일부터 일요일까지다.
- 주간 러닝 달성은 서로 다른 3일의 `COACH_COMPLETED` 러닝이 필요하다.
- 각 러닝은 10분 이상이어야 한다.

자동 테스트에서 04시 경계, 같은 날 중복 제거, 서로 다른 3일 계산을 검증했다.

## 활동 출처와 인정

| 출처 | 개인 움직임 스트릭 | 주간 경쟁 러닝 |
|---|---:|---:|
| `COACH_COMPLETED` | 기준 충족 시 포함 | 러닝 10분 이상이면 포함 |
| `HEALTH_LINKED` | 기준 충족 시 포함 | 현재 코드에서는 제외 |
| `SELF_LOGGED` | 기준 충족 시 포함 | 제외 |
| `CREW_ATTENDANCE` | 기준 충족 시 포함 | 현재 코드에서는 제외 |

회복은 5분 이상, 러닝과 걷기는 10분 이상일 때 개인 움직임으로 인정한다.

## 누적 티어

| 누적 주간 달성 | 티어 |
|---:|---|
| 0~3주 | 새싹러너 |
| 4~11주 | 러너 |
| 12~25주 | 꾸준러너 |
| 26~51주 | 페이스메이커 |
| 52주 이상 | 러닝마스터 |

티어는 저장된 활동 전체에서 3일 이상 달성한 주의 수로 계산한다.

## 현재 배지

| ID | 표시명 | 조건 |
|---|---|---|
| `first-coach` | 첫 코칭 | 러닝 기록 1회 |
| `streak-3` | 3일의 리듬 | 최고 스트릭 3일 |
| `streak-7` | 한 주의 리듬 | 최고 스트릭 7일 |
| `streak-14` | 두 주의 리듬 | 최고 스트릭 14일 |
| `streak-30` | 한 달의 리듬 | 최고 스트릭 30일 |
| `run-10` | 열 번의 출발 | 러닝 기록 10회 |
| `distance-3k` | 첫 3K | 단일 활동 거리 3km 이상 |
| `distance-5k` | 첫 5K | 단일 활동 거리 5km 이상 |
| `distance-10k` | 첫 10K | 단일 활동 거리 10km 이상 |

현재 `first-coach`와 러닝 횟수 배지는 활동 출처를 별도로 제한하지 않고 `kind === run`인 기록 수를 사용한다.

## 구현되지 않은 규칙

- 60·100·200·365일 스트릭 배지
- 주간 4·12·26·52주 배지
- 누적 50·100회와 10K 누적 배지
- 첫 대회 목표, 첫 크루, 첫 글, 첫 응원 배지
- 스트릭 보호권
- 서버 권위 배지 재계산 작업자
- 공개 배지 revoke audit 실행 경로

위 항목은 `NOT_IMPLEMENTED`다.

## 권위 경계

기기에서는 즉시 사용자 경험을 위해 로컬 활동으로 스트릭과 배지를 계산한다. Supabase 스키마에는 `badge_definitions`와 `user_badges`가 있으나 서버 권위 산정 작업은 구현·배포되지 않았다. 공개 프로필이나 리그에 사용할 서버 검증은 `BLOCKED_EXTERNAL`이다.
