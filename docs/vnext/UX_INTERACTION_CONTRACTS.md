# 러닝봄 vNext UX 상호작용 계약

## 상태 표기

- `PASS_CODE`는 현재 코드에서 흐름을 확인했다는 뜻이다.
- `PASS_TEST`는 로컬 자동 테스트가 통과했다는 뜻이다.
- `NOT_RUN`은 실행 검증을 하지 않았다는 뜻이다.
- `BLOCKED_EXTERNAL`은 실기기나 외부 계정이 필요하다는 뜻이다.

## 공통 계약

1. 핵심 대회·러닝화·코칭 기능은 로그인 없이 사용할 수 있어야 한다.
2. 화면의 선택 상태는 탭 이동만으로 초기화하지 않는다.
3. 버튼과 입력은 기능이 연결된 경우에만 활성화한다.
4. 외부 공식 페이지는 OS 브라우저로 연다.
5. 서버가 없으면 소셜 기능만 축소하고 코어 기능은 유지한다.
6. 앱은 가짜 사용자, 가짜 게시물, 추정 가격을 표시하지 않는다.

## 홈 계약

- Today Run은 한 장만 표시한다.
- 홈에는 시간 버튼 배열이나 세션 종류의 큰 버튼 배열을 두지 않는다.
- `변경`과 `시작`은 모두 시작 탭으로 이동한다.
- 스트릭 행은 현재 연속 일수와 주간 러닝 `N/3회`만 간결하게 표시한다.
- 대회는 접수 중 또는 접수 예정인 항목만 최대 3개 표시한다.
- 커뮤니티 데이터가 없으면 빈 상태를 표시하며 콘텐츠를 만들어내지 않는다.

상태는 `PASS_CODE`다. 실제 휴대전화 상호작용은 `NOT_RUN`이다.

## 탐색 계약

### 대회

- 검색, 지역, 거리, 접수 상태를 조합할 수 있어야 한다.
- 공식 링크와 알림 예약·취소를 유지한다.
- 딥링크 또는 알림 응답의 `raceId`가 있으면 탐색 화면의 해당 대회 맥락으로 전달한다.
- 원격 데이터 실패 시 번들 데이터를 사용한다.

기존 대회 전체 회귀 상태는 `RACE_REGRESSION_MATRIX.md`를 정본으로 한다.

### 러닝화

- 추천 결과는 최대 3개다.
- 비교함은 최대 3개다.
- 가격을 확인하지 못한 경우 가격을 추정하지 않는다.
- 공식 사실, 편집 설명, 고려할 점을 분리한다.
- 구매 링크는 공식 HTTPS URL만 사용한다.

자동 테스트에서 8개 브랜드, HTTPS 출처, 가격 `null`, 결정적 추천을 검증했다. 이 부분은 `PASS_TEST`다.

## 시작 계약

- 슬라이더는 10분부터 120분까지 5분 간격이다.
- 직접 입력은 10부터 120 사이의 정수만 허용한다.
- 잘못된 입력은 인라인 오류로 표시한다.
- 최근 시간, 유형, 안내량, 음성 속도를 저장한다.
- 코칭 진행 중에는 새 세션 시작 버튼을 비활성화한다.
- 네이티브 세션은 일시정지, 재개, 종료를 제공한다.
- fallback 세션은 사용자가 완료를 확인해야 활동으로 저장한다.
- 네이티브 세션 완료는 한 번만 저장한다.

코드 상태는 `PASS_CODE`다. 실제 백그라운드·잠금 화면 동작은 `BLOCKED_EXTERNAL`이다.

## 커뮤니티 계약

- 공개 피드는 비로그인 읽기를 허용한다.
- 형식이 잘못된 공개 글은 버리고 정상 행만 표시한다.
- 응원은 `응원해요`, `멋져요`, `함께해요`, `꾸준해요` 네 가지다.
- 사용자 한 명이 게시물 하나에 가지는 반응은 하나이며 변경 또는 취소할 수 있게 DB 키가 구성돼 있다.
- 쓰기는 `NORMAL` 모드와 로그인 상태에서만 허용한다.
- `READ_ONLY_COMMUNITY`와 `CORE_ONLY`에서는 쓰기를 차단한다.

공개 글 스키마와 반응 종류 자동 테스트는 `PASS_TEST`다. 실제 Supabase 세션과 쓰기 흐름은 `BLOCKED_EXTERNAL`이다.

## 마이 계약

- 로컬 활동은 JSON 형태로 내보낼 수 있다.
- 로컬 활동 삭제는 활동, 동기화 큐, 배지 진행, 일일 진행을 함께 삭제한다.
- 마지막 로그인 수단은 해제할 수 없다.
- 계정 삭제는 로그인 사용자의 `deletion_jobs` 요청으로 기록한다.
- 사용자 선택 동네는 법적 주소 인증이나 실거주 인증으로 표현하지 않는다.
- 앱 정보에는 콘텐츠와 DB 버전을 구분해 표시한다.

## 반응형·접근성 계약

- 공통 버튼 최소 높이는 48dp를 지향한다.
- 주요 상호작용 요소에는 `accessibilityRole` 또는 `accessibilityLabel`을 사용한다.
- 넓은 화면은 최대 너비와 내비게이션 레일을 사용한다.
- 입력 화면은 키보드 회피와 `keyboardShouldPersistTaps="handled"`를 사용한다.

TalkBack, 200% 글자, 320px, 390px, 430px, 768px 실제 렌더는 `NOT_RUN`이다. 현재 앱 설정은 light 스타일이며 다크 테마 구현은 확인되지 않았다.
