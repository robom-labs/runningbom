# 러닝봄 vNext 제품 정보구조

## 문서 범위

이 문서는 현재 `apps/mobile` 코드에서 확인한 화면 구조와 기능 경계를 기록한다. 제품 제안서가 아니며, 코드에 없는 기능을 구현된 것처럼 다루지 않는다.

## 전역 내비게이션

| 탭 | 현재 화면 | 핵심 역할 |
|---|---|---|
| 홈 | `HomeScreen` | 오늘의 러닝, 작은 스트릭 진행, 공개 피드 상태, 다가오는 대회, 러닝화, 크루 일정 |
| 탐색 | `ExploreScreen` | 대회, 러닝화, 출시 예정 러닝화 |
| 시작 | `StartScreen` | 코칭 시간과 유형 설정, 기기 음성 코칭 시작 |
| 커뮤니티 | `CommunityScreen` | 공개 피드, 크루, 리그의 현재 연결 상태 |
| 마이 | `MyScreen` | 프로필, 활동, 배지, 관심 항목, 계정과 앱 정보 |

휴대전화는 하단 탭을 사용하고, 화면 폭이 768px 이상이면 왼쪽 내비게이션 레일을 사용한다. 마지막으로 선택한 탭은 `runningbom:vnext:preferences:v1`에 저장한다.

근거는 `apps/mobile/app/navigation/AppNavigator.tsx`와 `apps/mobile/services/storage/preferences.ts`다.

## 홈

현재 표시 순서는 다음과 같다.

1. 러닝봄 워드마크와 태그라인
2. Today Run 한 장
3. 현재 스트릭과 이번 주 러닝 3회 목표
4. 커뮤니티 하이라이트
5. 다가오는 대회 최대 3개
6. 러닝화 최대 4개
7. 크루 다음 일정

가짜 사용자나 가짜 피드는 만들지 않는다. Supabase 공개 피드가 연결되지 않은 상태에서는 빈 상태를 표시한다.

## 탐색

### 대회

- 검색
- 지역 필터
- 거리 필터
- 접수 상태 필터
- 공식 페이지 열기
- 접수 알림 예약과 취소
- 원격 데이터와 번들 fallback
- `runningbom://race/{raceId}` 형식의 대회 딥링크

### 러닝화

- 공식 출처가 연결된 8개 모델
- 표면, 거리, 우선순위, 예산 질문
- 결정적인 최대 3개 추천
- 최대 3개 비교
- 현재 러닝화 저장
- 출시 예정과 국내 확인 상태 구분

추천 점수는 표면, 거리, 우선순위를 사용하고, 공식 가격이 확인된 제품에 한해서만 예산 적합도를 반영한다. 가격이 미확인인 제품은 예산 조건으로 임의 감점하지 않는다.

## 시작

- 10분부터 120분까지 5분 단위 슬라이더
- 10분부터 120분 사이의 정수 직접 입력
- 추천 세션 4개와 전체 세션 11개
- 안내량 3단계
- 음성 속도 설정
- Android 네이티브 백그라운드 코치
- 네이티브 코치 미지원 시 화면 안내와 시작 음성 fallback

Android가 아닌 환경의 fallback은 반복 백그라운드 큐를 제공하지 않는다.

## 커뮤니티

코드에 정의된 모드는 `NORMAL`, `LIMITED_WRITE`, `READ_ONLY_COMMUNITY`, `CORE_ONLY`다. Supabase가 없으면 `CORE_ONLY`이며, Supabase가 있어도 모드를 지정하지 않으면 `READ_ONLY_COMMUNITY`다.

현재 앱 화면은 공개 피드 읽기와 서버 상태 표시를 중심으로 한다. 글쓰기, 응원, 신고, 차단, 크루 생성과 참석을 위한 서비스 함수와 DB 계약은 있으나 전체 쓰기 UI는 완성되지 않았다.

## 마이

- 닉네임과 소개
- 현재 스트릭, 최고 스트릭, 이번 주 러닝
- 배지 보관함
- 최근 로컬 활동
- 현재 러닝화와 관심 대회·러닝화
- 사용자가 직접 선택한 동네
- 리그 참여 선택
- 로그인 제공자 상태
- 로컬 데이터 내보내기와 삭제
- 로그인 상태의 계정 삭제 요청
- 앱, 대회, 러닝화, 코칭, 배지, DB 버전

## 로그인 경계

대회 탐색, 러닝화 탐색, 코칭, 로컬 활동과 배지는 로그인 없이 작동하도록 분리돼 있다. 소셜 쓰기와 동기화는 Supabase 및 제공자 설정이 있어야 한다.

## 현재 제외 또는 미구현

- GPS 경로 기록과 백그라운드 위치 추적
- Health Connect 실제 연결
- 실시간 위치 공유
- 1대1 메시지
- 게시물 사진과 영상
- 광고와 제휴 추적
- 실시간 가격과 재고
- 동네 경계 GeoJSON과 point-in-polygon 판정
- 서버 권위 배지 산정과 리그 정산 작업자
- 다른 계정 간 자동 병합

SELF_LOGGED 로컬 기록은 사용자가 마이 화면에서 명시적으로 확인한 경우에만 현재 계정으로 idempotent 동기화한다. 자동 병합은 하지 않는다.
