## 번호를 앞에 붙이는 이유

전에는 이랬습니다.

```
RUNNINGBOM_V4_UPGRADE_SPEC.md
RUNNINGBOM_EXECUTION_STATE.md
RUNNINGBOM_GAP_REPORT_FOR_GPT.md
```

셋 다 `RUNNINGBOM_`으로 시작해서, 목록에서 **앞글자만 봐서는 구분이 안 됐습니다.**
폰이나 좁은 창에서는 뒷부분이 잘려서 더 심했습니다.

지금은 번호가 앞에 있어서 **한 글자만 봐도 갈립니다.**

---

## 앞으로 문서를 더할 때 규칙

```
<번호>-<버전>-<무슨 문서인지>.md
```

- **번호 두 자리**를 앞에 붙입니다. 파일 목록이 저절로 읽는 순서대로 정렬됩니다.
- **버전(V4·V5…)** 을 넣습니다. 어느 시기 문서인지 열지 않고 압니다.
- **한글로 무슨 문서인지** 씁니다. 영문 약자는 나중에 자기가 쓴 것도 못 알아봅니다.

번호는 **다시 쓰지 않습니다.** V5 기획서를 쓰면 `01`이 아니라 `04`입니다.
같은 번호를 재사용하면 "01이 두 개"가 되어 처음 문제로 돌아갑니다.

예정:

```
04-V5-기획서.md        ← GPT 답을 받아 반영한 다음 버전 기획
05-V5-실행상태.md
```
