| 아픈 신호 2번 | 쉬라고 함 |
| 아픈 신호 1번 | 가볍게 |
| "힘들었다" 2번 | 계획 회차 대신 회복 20분 |

| 3일 연속 달림 | 쉬라고 함 |

**이 숫자들(2번, 3일, 2일)에 근거가 없습니다.** 그냥 합리적으로 보여서 정했습니다.

## 10. 답변 형식 요청

답을 받아서 저희가 바로 코드로 옮길 수 있게, **이 형식으로** 부탁드립니다.

```
[질문 번호] Q3-1

【답】
(내용)

【확신도】 높음 / 보통 / 낮음
【근거 종류】 연구 / 코칭 통념 / 개인 경험 / 모름
【앱에 넣을 때 주의】
(잘못 적용하면 위험한 지점)
【우리가 쓰면 안 되는 표현】
(있다면)
```

**특히 부탁드리는 것**

1. **모르면 "모름"이라고 해 주세요.** 저희는 틀린 값보다 빈 값을 택합니다.
   실제로 러닝화 123종의 가격을 지어내지 않고 0%로 두고 있습니다.
2. **"연구 결과"와 "코칭 통념"을 구분**해 주세요. 둘 다 쓸모 있지만 다르게 다룹니다.
3. **의료 조언은 하지 마세요.** 저희는 "이러면 병원 가세요"까지만 말할 수 있습니다.
4. **한국 기준**으로 답해 주세요(가격·대회·브랜드 유통).

## 11. 이 문서를 쓴 사람이 이미 아는 것 (중복 답변 방지)

아래는 이미 해결했으니 답하지 않으셔도 됩니다.

- 연속 기록(streak)이 러너에게 해롭다 → 이미 안 씁니다. 대신 "이번 달 지도"를 씁니다.
- 이모지 난이도가 사람마다 다르게 읽힌다 → 이미 말로 고르는 3지선다로 바꿨습니다.
- 가격 없는 상품 목록은 쓸모없다 → 알고 있고, 가격대 범위로 임시 대응 중입니다.
- 온보딩이 묻기만 하고 아무것도 안 해 주면 부담이 된다 → 이미 계획을 깔아 줍니다.
