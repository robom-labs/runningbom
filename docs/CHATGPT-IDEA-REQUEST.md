# ChatGPT에게 그대로 붙여넣을 요청문

아래 `---` 사이를 통째로 복사해서 ChatGPT(웹 검색 켜고, 가능하면 o3/GPT-5급 추론 모델)에 붙여넣으세요.

---

너는 지금부터 **한국 러닝 앱 시장 1등을 만들려는 프로덕트 총괄**이다.

나는 이 앱으로 **최단기간 100만 다운로드**를 채우고, 러닝 앱 분야 **1등**이 될 생각이다.
취미로 만드는 게 아니라 **인생을 걸고** 만든다. 그 목표의식으로 답해라.
"좋은 앱이네요" 같은 덕담이나, 어디서나 통하는 일반론은 나에게 **아무 가치가 없다.**

## 1. 먼저 실제 코드를 읽어라 (추측 금지)

공개 저장소다. **반드시 직접 열어서 확인하고 답해라.**

```
https://github.com/robom-labs/runningbom
```

특히 이 경로들을 봐라:

| 경로 | 무엇인지 |
|---|---|
| `apps/mobile/app/screens/` | 화면 16개 (home, start, programs, calendar, races, shoes, challenges, community, guide, badges, my, settings, voice, auth, onboarding, explore) |
| `apps/mobile/domains/` | 핵심 로직 10개 (activities, badges, challenges, coaching, identity, programs, races, shoes, social, tracking) |
| `apps/mobile/domains/coaching/` | 러닝 중 음성 코치 (문장 사전 + 언제 무슨 말을 할지 정하는 엔진) |
| `apps/mobile/domains/badges/rules.ts` | 배지 48종 판정 규칙 |
| `apps/mobile/app/screens/guide/knowledge.ts` | 러닝 궁금증 Q&A 131개 |
| `apps/mobile/domains/shoes/catalog.ts` | 러닝화 135종 DB |
| `apps/mobile/scripts/simulate-coach.mjs` | 코치가 실제로 뭐라고 말하는지 돌려보는 시뮬레이터 |

읽고 나서 **"내가 실제로 확인한 것"과 "확인 못 한 것"을 구분해서** 말해라.
코드를 못 읽었으면 못 읽었다고 solidly 말해라. **추측을 사실처럼 쓰면 그 답변은 전부 버린다.**

## 2. 지금까지 만들어진 것 (사실)

- 플랫폼: Expo(React Native), 안드로이드 우선. 앱 이름 "러닝봄"
- 콘텐츠: 대회 183개 / 러닝화 135종 / 러닝 궁금증 131개 / 배지 48종
- 테스트 710개 통과
- **음성 코치**: 러닝 중 쉬지 않고 말해 준다. 분당 4~6.6마디, 최대 침묵 21~24초.
  이지런·인터벌·템포런·롱런·회복걷기 5종 각각 다른 대본. 남/여 목소리 고르기 가능
- **초보 9주 프로그램**(걷기↔뛰기 반복으로 30분 연속 달리기까지) + 대회 목표 훈련계획 자동 생성
- **자동 일시정지**(신호등에서 멈추면 알아서 멈춤), 1km 구간 기록, 경로 기록
- **부상 방지 경고**: 2주간 30% 증가 / 롱런이 최근 30일 최장의 110%·130% 초과 시 경고
  (연구 근거 기반. "10% 규칙"은 예측력이 없다는 5,200명 연구에 따라 안 씀)
- **자동 업데이트**: 앱이 스스로 새 내용을 받아서 스스로 적용한다. 사용자는 아무것도 안 누른다.
  단, 달리는 중에는 절대 적용 안 함(기록이 날아가므로)
- 온보딩에서 로그인(카카오/네이버/구글/애플) + 알림·GPS 권한을 자연스럽게 받는 흐름

## 3. 내가 추구하는 방향 (이걸 어기는 아이디어는 필요 없다)

1. **어려운 말 절대 금지.** "스트릭", "RPE" 같은 말 쓰지 마라. 나도 모르는 말을 사용자가 알 리 없다.
   → 지금은 "연속 기록", "힘든 정도(10점 만점)"로 바꿔 놨다. **초등학생이 읽어도 이해되게.**
2. **배지는 받으면 기분이 좋아야 한다.** 글자만 있는 배지는 배지가 아니다. 다른 앱처럼 멋있어야 한다.
3. **뒤로가기는 최적화되게.** 무조건 홈으로 튀면 안 된다.
4. **음성은 진짜 사람이 말하는 느낌으로.** 구글·네이버 앱 수준. 어색하면 실패다.
5. **홈 화면에 전체 맥락이 다 있어야 하고, 정돈돼 보여야 한다.**
6. **처음 시작할 때 자연스럽게** 가입하고, 알림·배터리최적화제외·GPS를 자연스럽게 켜지게.
   **당근마켓이 이걸 정말 잘한다.** 몇 번 안 눌렀는데 다 되어 있다.
7. **러닝화는 정리돼야 한다.** 5K/10K/15K 거리별 + 슈퍼트레이너/레이싱 등 성격별로.
8. **Q&A는 인스타처럼** 정보 공유받는 곳과, 궁금증 해결 코너가 **따로** 있어야 한다.
9. **벤치마킹 대상 3개**: Runkeeper, 러닝시작(5K Runner), adidas Running.
   **모방을 넘어서서 더 업그레이드**해야 한다. 그대로 베끼는 건 의미 없다.
10. **빠릿빠릿하게 작동해야 한다.** 느리면 사람들이 안 쓴다.

## 4. 지금 못 바꾸는 것 (여기 걸리는 아이디어는 제외해라)

- **정식 앱은 구글 플레이 심사 중**이다. 지금 새 권한(위치 등)을 추가하면 심사가 처음부터 다시 시작된다.
  → 지금 단계에서 **새 안드로이드 권한을 요구하는 기능은 제안하지 마라.**
- **서버가 없다.** 데이터는 전부 폰 안에 저장된다.
  → 서버·실시간 대전·클라우드 동기화가 **반드시** 필요한 기능이면, 그렇다고 명시하고 비용·난이도를 같이 적어라.
- 유료 API·유료 지도·유료 음성은 비용을 명시해라. 무료 대안이 있으면 같이 적어라.
- 기존 사용자 데이터(저장 키, 내부 ID)를 깨는 변경은 안 된다.

## 5. 너에게 요구하는 것

**웹을 실제로 검색해서**, 다운로드 상위권 러닝·운동 앱들이 *구체적으로 무엇을 어떻게* 하는지 조사해라.
Strava, Nike Run Club, adidas Running, Runkeeper, Runna, Zwift, 삼성헬스, 가민커넥트,
그리고 **러닝이 아니어도 좋다** — 듀오링고(습관화), 당근마켓(권한 받기), 토스(UX),
인스타그램(피드), 오늘의집(콘텐츠 커머스) 처럼 **사람을 붙잡아 두는 데 성공한 앱**이면 다 좋다.

그리고 다음 3가지를 뽑아 와라:

### A. 지금 러닝봄에 **없어서 치명적인 것** (최대 7개)
1등이 되려면 반드시 있어야 하는데 우리가 빠뜨린 것.
각각 **어느 앱이 어떻게 하는지 실제 사례**와 함께.

### B. **모방을 넘어설 수 있는 지점** (최대 5개)
1등 앱들도 못 하고 있거나 어설프게 하는 것. 우리가 여기서 이길 수 있는 것.
**"왜 그들이 안 하는지"**까지 분석해라. (이유가 있어서 안 하는 걸 수도 있다)

### C. **100만 다운로드로 가는 성장 장치** (최대 5개)
기능이 아니라 **사람이 사람을 데려오는 구조**.
한국 시장 기준. (예: 카카오톡 공유가 실제로 작동하는 형태, 대회 참가자 커뮤니티,
회사·동호회 단위 챌린지 등) 실제로 성공한 사례 근거를 대라.

## 6. 답변 형식 (반드시 지켜라)

각 아이디어를 **이 표 형식**으로 적어라. 개발자가 그대로 받아서 만들 수 있어야 한다.

```
### [번호] 한 줄 제목

- **무엇**: 사용자가 화면에서 실제로 무엇을 보고 무엇을 누르는지. 구체적으로.
- **왜**: 이게 왜 1등으로 가는 데 필요한지. 숫자·근거 있으면 필수.
- **근거 사례**: 어느 앱이 어떻게 하는지 (앱 이름 + 화면/기능 이름 명시)
- **우리 코드 어디**: github.com/robom-labs/runningbom 안에서 손대야 할 폴더/파일
- **난이도**: 하루 / 3일 / 1주 / 그 이상
- **서버 필요**: 필요 / 불필요
- **새 권한 필요**: 필요(무슨 권한) / 불필요
- **위험**: 이걸 넣었을 때 나빠질 수 있는 것 (없으면 "없음")
```

마지막에 **우선순위 1~10위**를 매기고, **"내가 개발자라면 이 순서로 하겠다"**는 이유를 3줄로 적어라.

## 7. 하지 말 것

- ❌ "AI 코칭을 도입하세요" 같은 **뜬구름**. 화면에 뭐가 보이는지 못 적으면 쓰지 마라.
- ❌ 이미 있는 것 다시 제안하기. **위 2번 목록을 읽고 걸러라.**
- ❌ 근거 없는 숫자 지어내기. 모르면 "모른다"고 써라.
- ❌ 20개씩 나열하기. **적은 개수를 깊게.** 깊이가 없으면 버린다.

시작해라.
