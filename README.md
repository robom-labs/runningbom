# 러닝봄

러닝봄은 **처음 달리는 사람부터 목표 대회를 준비하는 러너까지**, 오늘 할 운동을 정하고 음성 코칭과 함께 실행하며 기록·대회·러닝화를 한곳에서 관리하는 로봄의 러닝 앱입니다.

단순한 대회 알림 앱이 아닙니다. 정식 앱은 현재 Google Play 비공개 테스트·심사 흐름을 보호하기 위해 새 위치 권한을 추가하지 않고 **시간 기반 음성 코칭과 로컬 기록**을 중심으로 제공하며, 별도 Preview 빌드에서 GPS 거리·페이스·자동 멈춤·1km 구간 기록을 검증합니다.

## 지금 제공하는 핵심 경험

- **오늘의 러닝 한 장**: 기록·주간 목표·계획·목표 대회를 바탕으로 오늘 무엇을 할지 쉬운 문장으로 제안
- **음성 코치**: 이지런·인터벌·템포런·롱런·회복걷기 등 유형별 안내와 기기 한국어 음성 선택
- **9주 달리기 시작**: 걷기와 달리기를 섞어 30분 연속 달리기까지 이어지는 초보 프로그램
- **목표 대회 준비**: 대회일까지 남은 기간과 최근 기록을 바탕으로 주차별 계획 제시
- **대회 탐색·알림**: 국내 대회 일정, 지역·거리·접수 상태, 공식 링크와 접수 시작 로컬 알림
- **기록·통계·배지**: 기기 안에 활동을 저장하고 주간 목표, 연속 기록, 최고기록과 배지 진행을 확인
- **러닝화 탐색**: 갈래·거리·실력·가격대별 탐색, 추천, 비교, 관심 신발과 현재 신발 저장
- **기록 공유 준비**: 내 기록을 카드로 만들어 원하는 곳에 공유. 실제 커뮤니티 서버가 없을 때 가짜 사용자나 글을 만들지 않음
- **안전 우선**: 무리한 증가와 긴 거리 경고, 저장 실패 안내, 검증되지 않은 대회 시각·링크 제외

## 저장과 개인정보

- 기본 기록과 설정은 기기에 저장합니다.
- 로그인 없이 핵심 기능을 사용할 수 있습니다.
- 공개 클라이언트 변수(`EXPO_PUBLIC_*`)에는 비밀값을 넣지 않습니다.
- 운영 키·서명 인증서·스토어 자격 증명은 저장소가 아니라 EAS·Supabase·스토어의 비밀 저장소에서 관리합니다.

## 저장소 구조

```text
apps/mobile/
  app/                 화면·내비게이션·디자인 시스템·공용 상태
  domains/             활동·코칭·프로그램·대회·러닝화·배지·소셜 핵심 규칙
  services/            SQLite·설정·음성·업데이트·선택적 Supabase 연결
  tests/               순수 규칙·출시 계약·회귀 테스트
outputs/pushrun-site/   기존 PWA 호환 사이트
scripts/                대회·정적 데이터 동기화와 출시 검증
```

## 개발·검증

```bash
# 저장소 루트: 웹 호환면·정적 데이터·출시 계약
npm ci
npm test
npm run build
npm run audit:prod

# 네이티브 앱
cd apps/mobile
npm ci
npm run check
npm run export:native
```

`apps/mobile`은 Expo SDK 57·React Native 기반의 독립 네이티브 앱이며 WebView가 아닙니다. 기존 저장 키와 내부 ID는 호환성을 위해 임의로 바꾸지 않습니다.

## Production과 Preview

| 구분 | 목적 | 위치 권한 | GPS 추적 | 원격 업데이트 |
|---|---|---:|---:|---:|
| Production | Google Play 정식 배포·심사 | 추가하지 않음 | 시간 기반 코칭 | 비활성 |
| Preview | 실기기 고급 기능 검증 | 앱 사용 중 위치 | 거리·페이스·자동 멈춤·구간·경로 | 호환 런타임에서 활성 |

정식 앱의 권한을 늘리는 변경은 Play 심사와 사용자 고지를 다시 검토한 뒤 별도 릴리스로 진행합니다.

## 대회 데이터

- 1차 확인: 공개 국내 대회 일정
- 상세 보강: 공식 대회 사이트와 검증된 출처
- 날짜·장소·거리·접수 기간과 HTTPS 공식 링크가 검증된 항목만 반영
- 출처 요청·정규화·검증 중 하나라도 실패하면 마지막 검증 데이터를 유지
- 예약 워크플로가 주기적으로 변경을 확인하고 웹·모바일 데이터 계약을 함께 검증
